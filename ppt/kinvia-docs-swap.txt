2. PROPOSED SOLUTION AND KEY FEATURES (numbered 1–9)
==============================================================
[1] REFINIX (178): Refinix is an offline-first, on-premise AI workbench that enables AI-assisted work while keeping sensitive information within the user's or organization's controlled environment.
    KINVIA  (170): Kinvia is a voice-first AI counselling platform that engages a learner and their parents in one session, in their regional language, on the phone the family already owns.

[2] REFINIX (258): It acts as a local AI harness rather than being tied to a single model. It connects users with local open-weight models, organizational knowledge, approved tools, controlled execution environments, security and governance controls, and trusted local compute.
    KINVIA  (242): It acts as a counselling layer rather than a generic chatbot. It connects families with verified outcome data, NSQF pathways, scheme rules, human counsellors, consent and privacy controls, and district-level insight for scheme administrators.

[3] REFINIX (162): The system can select appropriate models as per the intent of the user and execute the task, returning it again to a local AI model which acts as an orchestrator.
    KINVIA  (151): The system detects each family member's concerns, such as income, social status or safety, and answers each one with evidence from verified local data.

[4] REFINIX (105): Refinix is designed to work with text, documents, scanned files, images, and all other supported formats.
    KINVIA  (97): Kinvia is designed to work with voice, text, WhatsApp and kiosk input across 22 Indian languages.

[5] REFINIX (98): Organizational documents can be indexed locally and retrieved to provide context for AI responses.
    KINVIA  (93): Post-training earnings, placement rates and progression are shown with their source and date.

[6] REFINIX (82): The AI can break a task into multiple steps and use approved tools to complete it.
    KINVIA  (72): The AI builds a plain-language path from course to job to NSQF level-up.

[7] REFINIX (90): Refinix can assist with code understanding, generation, modification, testing, and review.
    KINVIA  (92): Kinvia can hand a family to a live counsellor with a summary, so no one repeats their story.

[8] REFINIX (113): AI-generated code and sensitive operations can be executed inside controlled environments with restricted access.
    KINVIA  (101): Every salary or placement figure comes from the verified outcome store; the AI never invents numbers.

[9] REFINIX (61): Important actions can require user approval before execution.
    KINVIA  (64): Each session ends with a Family Trust Card the family can share.

2.1 SYSTEM ARCHITECTURE
==============================================================
[1] REFINIX (106): Refinix follows a modular architecture to separate AI models, knowledge, tools, execution, and governance.
    KINVIA  (109): Kinvia follows a modular architecture to separate voice, counselling, verified data, escalation and insights.

[2] REFINIX (103): User Interface — Provides Chat, Documents, Code, Jobs, Models, Devices, Settings, and related controls.
    KINVIA  (104): Family Interface — Provides voice, chat, WhatsApp, kiosk, Trust Card and multi-speaker session controls.

[3] REFINIX (105): Coordinator / Agent Harness — Manages task planning, routing, workflow state, permissions, and execution.
    KINVIA  (106): Counselling Orchestrator — Manages the counselling graph, model routing, session state, consent and tools.

[4] REFINIX (86): Model Runtime — Runs approved open-weight models locally or on trusted infrastructure.
    KINVIA  (89): Voice & Model Runtime — Runs Indic speech and open-weight LLMs on India-resident servers.

[5] REFINIX (65): Knowledge Layer — Stores and approves organisational information.
    KINVIA  (67): Outcome Engine — Stores verified earnings, placement and NSQF data.

[6] REFINIX (86): Tool Layer — Provides controlled document, file, code, and task-specific capabilities.
    KINVIA  (88): Tool Layer — Provides outcome, pathway, scheme-eligibility and escalation tools via MCP.

[7] REFINIX (67): Sandbox Layer — Isolates potentially risky code and tool execution.
    KINVIA  (67): Grounding Guard — Blocks unverified numbers, unsafe advice and PII.

[8] REFINIX (72): Trusted Workers — Provide additional approved local computing resources.
    KINVIA  (78): Counsellor Desk — Lets human counsellors take escalated families with context.

[9] REFINIX (71): Evidence Layer — Records relevant execution and validation information.
    KINVIA  (75): Insights Layer — Maps objections and sentiment shifts by district for MSDE.

3. SECURITY AND PRIVACY
==============================================================
[1] REFINIX (35): Security is a core part of Refinix.
    KINVIA  (43): Privacy and trust are core parts of Kinvia.

[2] REFINIX (118): Data Sovereignty: Sensitive information is designed to remain within the local or organisation-controlled environment.
    KINVIA  (104): Parental Consent: A parent gives verifiable consent before any minor's data is stored (DPDP Rules 2025).

[3] REFINIX (83): Offline Operation: Normal AI workflows do not require public internet connectivity.
    KINVIA  (77): Data Minimisation: Only district, schooling and income bracket are collected.

[4] REFINIX (93): Least Privilege: Workers and tools receive only the access required for their assigned tasks.
    KINVIA  (90): Role-Based Access: Counsellors see only escalated families; administrators see aggregates.

[5] REFINIX (94): Sandboxing: Generated code and potentially risky operations are isolated from the main system.
    KINVIA  (90): Grounded Answers: Figures come only from verified data, with source, date and sample size.

[6] REFINIX (107): Model Provenance: Models can be tracked using source, version, licence, runtime, and file hash information.
    KINVIA  (89): PII Redaction: Phone numbers, Aadhaar and names are removed before any logs or analytics.

[7] REFINIX (87): Human Oversight: Sensitive or consequential actions can require explicit user approval.
    KINVIA  (68): Human Escalation: A family can reach a live counsellor at any point.

[8] REFINIX (162): Refinix does not claim absolute security. Instead, it provides technical controls intended to reduce unnecessary data exposure and improve organisational control.
    KINVIA  (150): Kinvia does not guarantee jobs or earnings. Instead, it provides verified evidence and human support so that every family can make an informed choice.
