# Kinvia Frontend

**Status: planned — no code yet.**

The prototype website (installable PWA) with three surfaces:

| Surface | Users |
|---|---|
| Family session | Learner + parents — voice-first, regional language, Evidence Cards, Trust Card |
| Counsellor Desk | Human counsellors — escalation queue and session summaries |
| Scheme Insights | Administrators — objection heatmap, confidence shift |

Design rules for low-literacy users: large touch targets, icons with every choice,
read-aloud on every screen, short sentences, high contrast, minimal typing.

For the initial prototype (P0-05) a static, clickable mockup is acceptable if it is
clearly labelled as a mockup.
